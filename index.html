Precedência de operadores

  • 1º ()
  • 2º **
  • 3º * / %
  • 4º + -
  • Relacionais: não possuem ordem definida
  • Ordem lógica: ! → && → ||

Operadores de Atribuição


var n = 3
n = n + 4   //  n += 4
n = n - 5   //  n -= 5
n = n * 4   //  n *= 4
n = n / 2   //  n /= 2
n = n ** 2  //  n **= 2
n = n % 5   //  n %= 5

Operadores de Incremento


var x = 5

++x
x++

--x
x--
++x incrementa o valor antes de usá-lo. x++ incrementa depois de usá-lo.

Operadores Relacionais

  • 5 > 2 → true
  • 7 < 4 → false
  • 8 >= 8 → true
  • 9 <= 7 → false
  • 4 != 4 → false
  • 5 == '5' → true
  • 5 === '5' → false
  • 5 !== '5' → true
O resultado sempre será booleano.
Evite usar ==. Prefira === para comparar tipo e valor.

Operadores Lógicos

  • ! → negação
  • && → e
  • || → ou

idade >= 15 && idade <= 17
estado == 'RJ' || estado == 'SP'
salario > 1500 && sexo != 'M'

Operador Ternário


media >= 7 ? "Aprovado" : "Reprovado"

Condições

Condições simples e compostas


  if (condição) {
    true
  }
  else if (condição) {
    true
  }
  else {
    false
  }

Condição múltipla


  switch (condição) {
    case valor1:
    // código
    break
    case valor2:
    // código
    break
    default:
    // código
  }

Exemplo de switch/case/default


  var agora = new Date()
  var diaSem = agora.getDay()
console.log(diaSem)
switch (diaSem){
    case 0:
        console.log('Domingo')
        break
    case 1:
        console.log('Segunda-feira')
        break
    case 2:
        console.log('Terça-feira')
        break
    case 3:
        console.log('Quarta-feira')
        break
        case 4:
        console.log('Quinta-feira')
        break
        case 5:
        console.log('Sexta-feira')
        break
        case 6:
        console.log('Sábado')
        break
        default:
        console.log('Dia inválido')
        break
      }
O switch é mais eficiente que if-else para muitas condições. Inclusive para o exemplo acima, onde o if-else seria mais complexo.
O break é necessário (obrigatório) para evitar que o código continue executando os próximos cases.
O switch só aceita números inteiros, strings ou booleanos. Não funciona com intervalos. Fazendo-o ser um pouco mais limitado que o if-else.

Estruturas de Repetição

  • for
  • while
  • do while

For:


  for (var c = 1; c <= 5; c++) {
    console.log(c)
  }
  for (inicio; condição; incremento) {
    // código
  }
O for é mais usado quando se sabe o número de repetições. O while é mais usado quando não se sabe o número de repetições.

While:


    var c = 1
    while (c <= 5) {
      console.log(c)
      c++
    }
O while é mais usado quando não se sabe o número de repetições. O for é mais usado quando se sabe o número de repetições.

Do While:


    var c = 1
    do {
      console.log(c)
      c++
    } while (c <= 5)
O do while é usado quando se quer que o código seja executado pelo menos uma vez, mesmo que a condição seja falsa.

Arrays/Vetores

  • Variáveis Simples
    • Só armazenam um valor por vez
  • Variáveis Compostas / Arrays / Vetores
    • São capazes de armazenar vários valores em uma mesma estrutura
    "Um array ou um vetor, ou uma variável composta é uma variável que tem vários elementos. Cada elemente é composto pelo seu valor e por uma chave de identificação."

    Gustavo Guanabara


Exemplos de manipulação de arrays:

let num = [5, 8, 2, 9, 3]
// //Adicionar elemento há um índice conhecido
num[5] = 9
// //Adicionar elemento e índice após o último elemento do vetor
num.push(1)
// //tamanho da array
num.length
// agrupa em ordem crescente
num.sort()
console.log(num)
console.log(`Nosso vetor tem ${num.length} elementos`)
console.log(num[0])

let valores = [8, 1, 7, 4, 2, 9]
// //percurso para exibição
for (let pos = 0; pos <= valores.length; pos++) {
  console.log(`A posição ${pos} tem o valor ${valores[pos]}`)
}
// para cada posição em "num" mostre o elemento dessa posição (.sort() para ordenar)
num = [4, 9, 6, 5, 1].sort()
for (let pos in num) {
  console.log(`A posição ${pos} tem o valor ${num[pos]}`)
}
// busca o índice (se o valor não for encontrado retorna -1)
num.indexOf(7)
Funções podem ser declaradas de várias formas, como funções nomeadas, funções anônimas, funções de seta (arrow functions) e funções de expressão.

Avançando em funções

São ações executadas assim que são chamadas ou em decorrência de um evento.

Uma função pode receber parâmetros e retornar um resultado.

Função com parâmetros e retorno


Síntaxe básica de uma função com parâmetros e retorno de valor:

function ação(parâmetro){
  //código
  return resultado
}
ação(5)
Ex:

function parimp(n){
  if (n % 2 == 0){
    return 'par'
  } else {
    return 'ímpar'
  }
}
// ⚠ chamada da função ⚠
let res = parimp(11)
A função acima mostra a estrutura básica de uma função com parâmetros e retorno de valor.

Função que verifica par ou ímpar


function parimpar(n){
  if(n%2==0){
    return `Par`
  } else {
    return `Impar`
  }
}
let res = parimpar(4)
console.log(res)
//ou console.log(parimpar(4))
A função acima recebe um parâmetro (n) e retorna um resultado (par ou ímpar). O resultado é armazenado na variável res.

Função com parâmetros padrão


//parâmetros pré definidos:
// function soma(n1=0, n2=0){...} n1=0, n2=0 <== define um valor padrão
function soma(n1, n2){
  return n1+n2
}

console.log(soma(2))
A função acima recebe dois parâmetros (n1 e n2) e retorna a soma dos dois. Se apenas um parâmetro for passado, o outro será undefined, resultando em NaN (Not a Number). Para evitar isso, podemos definir valores padrão para os parâmetros.

Função anônima atribuída a variável


let v = function(x){
  return x*2
}

console.log(v(5))
A função acima recebe um parâmetro (x) e retorna o dobro desse valor.

Função fatorial com loop


function fatorial(n){
  let fat = 1
  for (let c = n; c > 1; c--){
    fat *= c
  }
  return fat
}

console.log(fatorial(5))
A função acima recebe um parâmetro (n) e retorna o fatorial desse valor. O fatorial de um número n é o produto de todos os números inteiros positivos de 1 até n. Por exemplo, 5! = 5 x 4 x 3 x 2 x 1 = 120.

Função fatorial recursiva


// Recursividade
function fatorial(n){
  if (n == 1){
    return 1
  } else {
    return n * fatorial(n-1)
  }
}
console.log(fatorial(5))
//n! = n x (n-1)!
A função acima utiliza recursividade para calcular o fatorial de um número. Recursividade é uma técnica em que uma função chama a si mesma até atingir um caso base.
